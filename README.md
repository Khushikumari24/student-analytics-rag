# Student Intelligence Analytics System

A beginner-friendly project that teaches ML math concepts through hands-on code.

## What this project covers

- **Linear Algebra** — matrix operations, dot products, PCA, cosine similarity
- **Calculus** — derivatives, gradient descent, learning curves
- **Probability** — normal distribution, Bayes' theorem, Monte Carlo simulation
- **Statistics** — mean, std, correlation, percentiles
- **RAG Chatbot** — PDF question answering with Mistral-7B + FAISS
